# Page sections

Sections are grouped by page: `home/` holds the hero, intro and stats,
showreel, stacked case studies, challenges band, client strip, process,
services band, and FAQ. Add `expertise/`, `services/`, `work/`, `about/`,
`pricing/`, and `contact/` folders as those pages are designed.

Pages compose sections. Text and data belong in `content/`; shared controls in
`components/ui/`; layout helpers in `components/layout/`; scroll-reveal
helpers in `components/motion/`.
